# Cashflow — Documentação de Funcionalidades

Aplicação de controle de fluxo de caixa pessoal. Permite registrar ganhos, despesas,
parcelamentos, cartões de crédito, veículos e abastecimentos, e a partir disso gerar
uma **projeção financeira** dos próximos meses e o **saldo remanescente** de cada mês.

Cada funcionalidade está documentada em um arquivo próprio na pasta
[`funcionalidades/`](funcionalidades/).
